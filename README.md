# Chicken Animation

A playful chicken animation built with plain HTML, CSS and a bit of JavaScript.

![Chicken animation screenshot](./Screenshot%202024-08-30%20103016.png)

## Overview

This small project demonstrates a CSS-driven animation of a chicken created for fun and learning. It's lightweight, dependency-free, and easy to read — a nice example for beginners exploring CSS animations and simple DOM interactions.

## Live demo

- Open `index.html` in your browser (double-click or serve with a static file server).
- The animation runs automatically.

## Features

- Pure HTML/CSS art and animation with minimal JavaScript.
- Responsive layout that centers the animation on the page.
- Commented and readable CSS so you can learn or tweak the animation.

## Files

- `index.html` — markup for the animation container and structure.
- `style.css` — styles and keyframe animations powering the chicken.
- `Screenshot 2024-08-30 103016.png` — screenshot used in this README.

## Technologies

- HTML
- CSS (animations & transforms)
- JavaScript (minimal, for any interactive bits)

## How to run

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Chicken-Animation.git

2. Open `index.html` in your web browser, or serve the folder with a static server (e.g., `npx http-server` or `python -m http.server`).
